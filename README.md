# yashwantsoni1.github.io

Personal site of Yashwant Soni — IIAI: Interferometry, Imaging, Artificial Intelligence.

## Publish on GitHub Pages
1. Create a public repository named exactly **yashwantsoni1.github.io**.
2. Upload everything in this folder (keep the `assets`, `images`, `files` folders).
3. Go to Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. After a minute the site is live at https://yashwantsoni1.github.io

## Add your content
- **Intro photos:** `images/profile-1.jpg` (portrait, 3:4) and `images/profile-2.jpg` (4:5).
- **Personal photos:** `images/photo-1.jpg` … `images/photo-9.jpg`. Edit captions in `photos.html`.
- **CV:** put your PDF at `files/cv.pdf`.
- **Text:** replace every `[bracketed]` placeholder in `research.html` and `resume.html`,
  and the email address in the footer of each page.

Empty photo slots show a "Add images/…" placeholder until the file exists.
All research figures are animated canvases drawn by `assets/main.js` (no images needed).
